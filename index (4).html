Full stack · Web app

Full Stack Zerodha Clone

MongoDBExpress.jsReact.jsNode.js

A trading platform clone where users buy, sell and track stocks in real time, modeled on a real brokerage app.

What I built

  • A React.js front end with reusable components for the dashboard, holdings, positions and order forms, so the UI stays consistent and easy to extend.
  • RESTful APIs in Node.js and Express.js for order placement, portfolio updates and trade history between client and server.
  • A secure login and session system, so each user can safely reach their own account, holdings and past trades.
  • Data modeled in MongoDB for fast, reliable reads and writes.
  • Dedicated pages for live portfolio value, current holdings and full trade history, with data refreshing smoothly across the app.

Python · Automation

Jarvis AI Assistant

PythonSpeech recognitionText-to-speech

A voice-controlled personal assistant that listens to spoken commands, processes them, and responds with speech or on-screen output.

What I built

  • Python speech recognition and text-to-speech libraries turn spoken input into text commands and generate natural voice responses.
  • Automation of everyday tasks by voice: web searches, setting reminders and managing emails.
  • Command-handling logic built in a modular way, so new voice commands can be added without changing existing code.
  • Better recognition through handling of different phrasings and partial matches, so the same request worded several ways is understood.
  • Basic error handling for commands the assistant does not recognize.
